# Linux अवलोकन

Chloros 1.2.0, Linux वर्कस्टेशनों, सर्वरों और NVIDIA Jetson एज डिवाइसों पर **CLI**और**Python SDK** के लिए नेटिव Linux समर्थन प्रदान करता है — जिसमें हेडलेस मल्टीस्पेक्ट्रल इमेज प्रोसेसिंग, साथ ही लाइव LATTICE कैमरा और DAQ लाइट-सेंसर नियंत्रण शामिल है।

{% hint style="info" %}
Linux पर कोई डेस्कटॉप GUI नहीं है। Chloros Desktop GUI केवल Windows पर उपलब्ध है। Linux उपयोगकर्ता Chloros के साथ [CLI](../CLI.md) और [Python SDK](../api-python-sdk.md) के माध्यम से इंटरैक्ट करते हैं। `.deb` आपके एप्लिकेशन मेनू में एक **Chloros CLI** प्रविष्टि जोड़ता है — यह बस `chloros-cli` चलाने वाला एक टर्मिनल एमुलेटर खोलता है।
{% endhint %}

##  उपयोगकर्ताओं को क्या मिलता है

* **Chloros CLI** — बैच प्रोसेसिंग, ऑटोमेशन और स्क्रिप्टिंग के लिए पूरा कमांड-लाइन इंटरफ़ेस
* **Chloros Python SDK** — रिसर्च पाइपलाइनों और कस्टम टूल्स के लिए प्रोग्रामैटिक Python इंटरफ़ेस (PyPI से इंस्टॉल करने योग्य, और `.deb` के अंदर एक संस्करण-मिलान वाले व्हील के रूप में भी बंडल किया गया)
* **LATTICE कैमरा नियंत्रण** — `chloros-cli lattice` और SDK के माध्यम से LATTICE कैमरों और समकालिक बहु-कैमरा सरणियों को खोजें, कनेक्ट करें, कॉन्फ़िगर करें और कैप्चर करें; `.deb` उन कैमरों के लिए आवश्यक Arena SDK रनटाइम को बंडल करता है
* **DAQ लाइट-सेंसर नियंत्रण** — DAQ-U/M/E सेंसरों को कनेक्ट करें, कैलिब्रेटेड स्पेक्ट्रा स्ट्रीम करें, और `chloros-cli daq pool-*` और SDK के माध्यम से `.daq` फ़ाइलें रिकॉर्ड करें
* **PTP टाइम सिंक** — Chloros बैकएंड PTP ग्रैंडमास्टर चलाता है, जिसके स्लेव LATTICE कैमरों और DAQ-E सेंसरों को किया जाता है; इसे `chloros-cli time-sync` से निरीक्षण करें, और `chloros-backend.service` systemd यूनिट के साथ हेडलेस रूप से चलाते रहें (देखें [Linux इंस्टॉलेशन](linux-installation.md#always-on-ptp-for-headless-hosts))
* **प्रोजेक्ट ऑटोमेशन** — `chloros-cli project` और SDK के `open_project` के साथ सेव किए गए प्रोजेक्ट्स को हेडलेस रूप से चलाएँ
* **जीपीयू एक्सेलेरेशन** — NVIDIA GPUs (डेस्कटॉप और जेटसन) पर CUDA-एक्सेलेरेटेड प्रोसेसिंग
* **डायनामिक कम्प्यूट एडैप्शन** — स्वचालित हार्डवेयर का पता लगाना और प्रोसेसिंग-रणनीति का चयन, जिसमें `CHLOROS_STRATEGY` ओवरराइड एक विशेषज्ञ एस्केप हैच के रूप में है
* **सभी प्रोसेसिंग सुविधाएँ** — Windows के समान पाइपलाइन: कैलिब्रेशन, विनेट सुधार, वनस्पति सूचकांक, और हर एक्सपोर्ट फॉर्मेट
* **Chloros+ सुविधाएँ** — मल्टी-थ्रेडेड (पाइपलाइन्ड) प्रोसेसिंग, टेक्सचर अवेयर डेबेयर, और कस्टम इंडेक्स, एक सशुल्क Chloros+ प्लान के साथ

## Linux उपयोगकर्ताओं को क्या नहीं मिलता है

* **डेस्कटॉप जीयूआई** — कोई ग्राफिकल इंटरफ़ेस नहीं; सभी इंटरैक्शन CLI या Python SDK के माध्यम से होता है
* **इमेज व्यूअर** — कोई इंटरैक्टिव इमेज व्यूअर, ग्रिड व्यू, या मैप मार्कर नहीं
* **दृश्य परियोजना प्रबंधन** — परियोजनाएँ CLI कमांड और SDK कॉल के माध्यम से बनाई और चलाई जाती हैं (हार्डवेयर स्वयं — कैमरे, सेंसर, कैप्चर — टर्मिनल से पूरी तरह से नियंत्रित रहता है)***

## लाइसेंस आवश्यकता

CLI और SDK तक पहुँच के लिए **पेड Chloros+ स्तर — कॉपर या उससे ऊपर**(कॉपर, ब्रॉन्ज़, सिल्वर, गोल्ड) की आवश्यकता है। मुफ़्त**आयरन** स्तर में कोई CLI / SDK पहुँच नहीं है। यह सीमा बैकएंड द्वारा लागू की जाती है, न कि केवल CLI द्वारा:

| स्थिति | बैकएंड प्रतिक्रिया |
| --- | --- |
| लॉग इन नहीं किया है | `401` with `error_code: AUTH_REQUIRED` |
| मुफ़्त आयरन टियर पर लॉग इन | `403` के साथ `error_code: PLAN_UPGRADE_REQUIRED` |

`chloros-cli status` किसी भी टियर पर काम करता है — यह गेट से छूट प्राप्त एकमात्र मार्ग है — इसलिए अस्वीकृति का कारण हमेशा दिखाई देता है।

## Linux पर शुरुआत करना

1. **Chloros इंस्टॉल करें** — `.deb` इंस्टॉल के लिए [Linux इंस्टॉलेशन](linux-installation.md) देखें
2. **सत्यापित करें** — `chloros-cli --version`, `Chloros CLI 1.2.0` प्रिंट करता है; `chloros-cli selftest` 7-चरणीय डायग्नोस्टिक चलाता है
3. **Python SDK** इंस्टॉल करें (वैकल्पिक) — `pip install chloros-sdk`
4. **साइन इन करें** — `chloros-cli login your@email.com 'your-password'` (प्रति मशीन एक बार, और हर पैकेज अपग्रेड के बाद फिर से)
5. **अपना पहला डेटासेट प्रोसेस करें** — `chloros-cli process ~/datasets/flight001`

NVIDIA Jetson के लिए, प्लेटफ़ॉर्म-विशिष्ट सेटअप, थर्मल व्यवहार, और फ़ील्ड डिप्लॉयमेंट के लिए समर्पित [NVIDIA Jetson गाइड](nvidia-jetson-guide.md) देखें।
