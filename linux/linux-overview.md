# Linux अवलोकन

Chloros 1.1.0 **CLI**और**Python SDK** के लिए मूल Linux समर्थन लाता है, जो Linux वर्कस्टेशन, सर्वर और NVIDIA पर हेडलेस मल्टीस्पेक्ट्रल इमेज प्रोसेसिंग को सक्षम करता है। जेटसन एज डिवाइस।

{% hint style="info" %}
**Linux पर कोई GUI नहीं।** Chloros डेस्कटॉप GUI केवल Windows पर उपलब्ध है। Linux उपयोगकर्ता [CLI](../CLI.md) और [Python SDK](../api-python-sdk.md) के माध्यम से Chloros के साथ इंटरैक्ट करते हैं।
{% endhint %}

| **टेक्सचर अवेयर डिबायर** | हाँ (Chloros+) | हाँ (Chloros+) | हाँ (Chloros+) | हाँ (Chloros+) |

## समर्थित आर्किटेक्चर

| वास्तुकला | विवरण | स्थापना विधि |
| --- | --- | --- |
| **amd64 (x86_64)** | मानक डेस्कटॉप/सर्वर प्रोसेसर (इंटेल, एएमडी) | `.deb` पैकेज |
| **arm64 (aarch64)** | एआरएम-आधारित प्रोसेसर, मुख्य रूप से एनवीडिया जेटसन | `.deb` पैकेज (जेटपैक 6) |

## समर्थित Linux वितरण

* **उबंटू 20.04+** (amd64)
* **डेबियन 11+** (amd64)
* **NVIDIA JetPack 6** (arm64 — Jetson प्लेटफ़ॉर्म)***

## Linux उपयोगकर्ताओं को क्या मिलता है

* **Chloros CLI** - बैच प्रोसेसिंग, ऑटोमेशन और स्क्रिप्टिंग के लिए पूर्ण कमांड-लाइन इंटरफ़ेस
* **Chloros Python SDK** - अनुसंधान पाइपलाइनों और कस्टम टूल में एकीकरण के लिए प्रोग्रामेटिक Python इंटरफ़ेस (`pip install chloros-sdk`)
* **GPU त्वरण** - NVIDIA GPU (डेस्कटॉप और जेटसन) पर CUDA-त्वरित प्रसंस्करण
* **डायनेमिक कंप्यूट अनुकूलन** - स्वचालित हार्डवेयर पहचान और प्रसंस्करण रणनीति अनुकूलन
* **सभी प्रसंस्करण सुविधाएँ** - Windows के समान मल्टीस्पेक्ट्रल प्रसंस्करण पाइपलाइन (अंशांकन, विगनेट सुधार, वनस्पति सूचकांक, सभी निर्यात प्रारूप)
* **Chloros+ विशेषताएं** - मल्टी-थ्रेडेड प्रोसेसिंग, टेक्सचर अवेयर डिबेयर, कस्टम इंडेक्स (Chloros+ लाइसेंस के साथ)

## Linux उपयोगकर्ताओं को क्या नहीं मिलता

* **डेस्कटॉप जीयूआई** - कोई ग्राफिकल इंटरफ़ेस नहीं; सभी इंटरैक्शन CLI या Python SDK के माध्यम से होते हैं
* **छवि दर्शक** - कोई इंटरैक्टिव छवि दर्शक, ग्रिड दृश्य या मानचित्र मार्कर नहीं
* **विजुअल प्रोजेक्ट प्रबंधन** - परियोजनाओं को CLI कमांड और SDK कॉल के माध्यम से प्रबंधित किया जाता है***

## Linux पर आरंभ करना

1. **Chloros इंस्टॉल करें** - `.deb` पैकेज इंस्टालेशन के लिए [Linux इंस्टालेशन](linux-installation.md) देखें
2. **Python SDK स्थापित करें** (वैकल्पिक) - `pip install chloros-sdk`
3. **अपना लाइसेंस सक्रिय करें** - `chloros-cli login your@email.com 'password'`
4. **अपना पहला डेटासेट संसाधित करें** — `chloros-cli process ~/datasets/flight001`

NVIDIA Jetson उपयोगकर्ताओं के लिए, प्लेटफ़ॉर्म-विशिष्ट सेटअप और अनुकूलन के लिए समर्पित [NVIDIA Jetson गाइड](nvidia-jetson-guide.md) देखें।
