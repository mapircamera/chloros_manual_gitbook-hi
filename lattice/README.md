# लैटिस कैमरे

LATTICE कृषि और वैज्ञानिक इमेजिंग के लिए MAPIR का एक मॉड्यूलर मल्टीस्पेक्ट्रल कैमरा सिस्टम है। हर LATTICE कैमरा सोनी IMX265 ग्लोबल-शटर सेंसर (**

3.1 MP, 3.45 µm पिक्सल**) पर बनाया गया है और एक**GigE Vision** डिवाइस के रूप में ईथरनेट पर कनेक्ट होता है।

Chloros 1.3.0 तीन सतहों से LATTICE कैमरों को लाइव नियंत्रित करता है — डिस्कवरी, लाइव पूर्वावलोकन, कैप्चर, और सिंक्रनाइज़्ड मल्टी-कैमरा ऐरे —:

| सतह    | कहाँ                                                          | प्लेटफ़ॉर्म                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| GUI        | **कैमरे** टैब Chloros साइडबार में                                      | Windows 10/11 x64                                        |
| CLI        | `chloros-cli lattice` कमांड फैमिली                           | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (जेत्सन) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |

> **हार्डवेयर की तलाश में हैं?**कैमरा मॉड्यूल, लेंस, फ़िल्टर और बैंड, फ़्रेम और माउंटिंग, केबल, PoE और ट्रिगर वायरिंग [**LATTICE उपयोगकर्ता मैनुअल**](https://mapir.gitbook.io/lattice-camera) में प्रलेखित हैं। यह अध्याय Chloros से कैमरों को ड्राइव करने को कवर करता है।

LATTICE कैप्चर मानक `.tif`/`.tiff` फ़ाइलें होती हैं, और Chloros हमेशा उन्हें कच्चे कैप्चर से शुरू करके प्रोसेस करता है। पूर्ण कमांड और API सतह के लिए [CLI संदर्भ](../reference/cli-reference.md) और [SDK संदर्भ](../reference/sdk-reference.md) देखें।

## दो सेंसर कॉन्फ़िगरेशन

| कॉन्फ़िगरेशन | सेंसर       | फ़िल्टर                                | एक कैमरा क्या प्रदान करता है                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| बायर कलर | ट्रिपल-बैंडपास फ़िल्टर                |**एक ही एक्सपोज़र से तीन कैलिब्रेटेड बैंड**                 |
| **M3M**| मोनोक्रोम   | एकल संकीर्ण-बैंड हस्तक्षेप फ़िल्टर |**एक कैलिब्रेटेड बैंड**; सूचकांकों के लिए कई M3M कैमरों को संयोजित करें |

क्योंकि एक M3M कैमरा एकल फ़िल्टर के पीछे मोनोक्रोम होता है, प्रत्येक बैंड को अपना स्वयं का एक्सपोज़र मिलता है। एक M3C कैमरा अपने सभी तीन बैंड को एक सेंसर एक्सपोज़र से कवर करता है।

## मॉडल स्ट्रिंग और नामकरण

हर कैमरा अपनी पहचान को GenICam `DeviceUserID` में एक मॉडल स्ट्रिंग के रूप में संग्रहीत करता है:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chloros इसे `LATT-` उपसर्ग के साथ प्रदर्शित करता है (उदाहरण के लिए `LATT-M3M-L87-F450`)। वही `LATT-…` स्ट्रिंग हर एक्सपोर्ट के EXIF `Model` टैग में लिखी जाती है और प्रोसेस किए गए प्रोजेक्ट्स में कैमरे के आउटपुट फ़ोल्डर के नाम के रूप में उपयोग की जाती है।

| घटक | मान                                                   | अर्थ                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| सेंसर    | `M3C` / `M3M`                                            | बायर कलर / मोनोक्रोम                                                                          |
| लेंस      | `L41` / `L87`                                            | यह संख्या **डिग्री में क्षैतिज दृश्य क्षेत्र** है: L41 = संकीर्ण (41°), L87 = चौड़ा (87°)    |
| फ़िल्टर    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) या `F<nm>` (M3M) | [फ़िल्टर और स्पेक्ट्रल बैंड](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) देखें |

मॉडल स्ट्रिंग आगे की सभी प्रक्रियाओं को संचालित करती है: Chloros, `DeviceUserID` + `DeviceSerialNumber` से सेंसर प्रोफ़ाइल, बैंड लेआउट, और फ़ैक्टरी कैलिब्रेशन को हल करता है। प्रत्येक कैमरे के लिए कॉन्फ़िगर करने के लिए कुछ भी नहीं है — [कैमरे कनेक्ट करना](connecting.md) देखें।

## फ़िल्टर और बैंड

बैंड सेंटर, FWHM एज और पूरा 23-SKU M3M कैटलॉग उत्पाद विनिर्देश हैं, इसलिए वे हार्डवेयर मैनुअल में होते हैं: [**फ़िल्टर और स्पेक्ट्रल बैंड**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

सॉफ़्टवेयर पक्ष पर क्या मायने रखता है: मॉडल स्ट्रिंग में फ़िल्टर कोड यह निर्धारित करता है कि Chloros कौन से उत्पाद बना सकता है। RGB-फ़िल्टर कैमरे (`FRGB`) केवल डेबयेर किए गए और प्रीव्यू उत्पाद उत्सर्जित करते हैं — एक ब्रॉडबैंड सेंसर के लिए प्रति-बैंड रेडियंस और रिफ्लेक्टेंस का कोई अर्थ नहीं होता, इसलिए Chloros उन्हें छोड़ देता है और ऐसा बताता भी है। हर कोई अन्य फ़िल्टर पूरी रेडियंस → रिफ्लेक्टेंस → इंडेक्स श्रृंखला देता है।

## रेडियोमेट्रिक कैलिब्रेशन पर एक नज़र

हर LATTICE कैमरे को फैक्ट्री में NIST-ट्रेस करने योग्य चेन के खिलाफ व्यक्तिगत रूप से कैलिब्रेट किया जाता है और यह प्रति-कैमरे प्रमाण पत्र के साथ शिप होता है। इसमें क्या शामिल है, इसका मापन कैसे किया जाता है और आप कितनी सटीकता का हवाला दे सकते हैं, यह हार्डवेयर मैनुअल में दिया गया है: [**फैक्ट्री रेडियोमेट्रिक कैलिब्रेशन**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration)।

सॉफ़्टवेयर की ओर से, जो बात मायने रखती है वह यह है कि जब कोई कैमरा कनेक्ट होता है तो Chloros सही कैलिब्रेशन को हल करता है और हर एक्सपोर्ट में लागू गुणांकों को स्थिर कर देता है — देखें [कैमरे कनेक्ट करना](connecting.md)।

## इस अध्याय में

* [कैमरे कनेक्ट करना](connecting.md) — ऑटो-डिस्कवरी, GUI कनेक्ट डायलॉग, CLI/SDK समकक्ष, और जब कोई कैमरा कनेक्ट होता है तो फैक्ट्री कैलिब्रेशन कैसे हल होता है (ऑन-कैमरा पैक बनाम क्लाउड)।
* [कैमरा सेटिंग्स](camera-settings.md) — कैमरों टैब में हर नियंत्रण: कैमरा सूची, प्रति-कैमरा सेटिंग्स पैनल, और एरे सेटिंग्स पैनल (ROI संपादक और संरेखण सहित)।
* [कैप्चर सेटिंग्स और मोड](capture.md) — सभी कैप्चर करें, एकल / निरंतर / अंतराल कैप्चर, एक्सपोर्ट प्रकार, और कैप्चर फ़ोल्डर लेआउट।
* [मल्टी-कैमरा ऐरे](arrays.md) — ऐरे कनेक्ट विज़ार्ड, सिंक-केबल प्रोब, बैंडविड्थ, PTP, और लाइव ऐरे व्यू।
* [मोनो कैमरे और वनस्पति सूचकांक](mono-indices.md) — M3M कैमरे और संरेखण → स्टैक → इंडेक्स वर्कफ़्लो।
